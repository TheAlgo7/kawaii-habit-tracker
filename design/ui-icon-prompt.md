# Generated theme artwork brief

The three theme artworks were generated with the built-in Imagegen tool and translated into optimized transparent WebP files under `public/ui-icons/`.

## Theme atlas

Create a two-by-two atlas on a perfectly flat `#ff00ff` chroma-key background. Match the approved watercolor cat illustration: hand-painted storybook gouache, warm brown ink outlines, restrained internal paper texture, slightly irregular contours, strong silhouettes, and an all-ages tone. The subjects are a terracotta sun with olive leaves, an aubergine crescent with a lantern-gold star, and a sage matcha cup on a closed book with a sprout. Keep one centered subject per quadrant, generous padding, no text, no faces, no emoji styling, no dividers, and no shadows.

The chroma background is removed with the Imagegen skill helper using a soft matte and despill. Each final asset is resized to 192 by 192 pixels and encoded as transparent WebP.

Habit tiles intentionally use native SVG shapes inside `HabitIcon.jsx`, not generated raster artwork. This preserves the crisp water-and-book visual language and lets the user-selected accent color recolor every habit consistently.
